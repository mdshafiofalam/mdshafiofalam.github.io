Created a high-fidelity prototype specifically aimed at immigrants to a new place.

Conceptualized the app idea, then refined it by comparing it against existing ones. Then created a low-fidelity (paper prototype) and evaluated the UI with real participants. Finally, made an interactive prototype and conducted usability evaluation using a Think-aloud session and UEQ-S analysis.
